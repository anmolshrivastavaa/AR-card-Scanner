📱 Augmented Reality Business Card Scanner

An Augmented Reality (AR) mobile application built with Unity 2022 LTS and Vuforia Engine. 
The app scans a college ID card (used as a marker) and augments it with interactive clickable elements such as LinkedIn, Codilio, and project links. A 3D avatar generated via Ready Player Me is also placed on the marker with animations.

✨ Features    

📷 Marker-based AR scanning using Vuforia.

👤 3D Avatar integration with animations.    

🔗 Clickable links (LinkedIn, Codilio, Projects) opening in browser.

🎨 Interactive UI & animations for smooth AR experience.

📱 Optimized for Android/iOS mobile devices.

🚀 Getting Started
Prerequisites

Unity 2022 LTS (or later LTS version recommended).

Vuforia Engine installed (via Unity Package Manager).


⚡ Challenges Faced

Material issues in Unity latest version → solved by using Unity 2022 LTS.

Build error loading wrong scene → fixed by setting MainScene in Build Settings.
